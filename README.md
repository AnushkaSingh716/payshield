# PayShield

PayShield predicts whether a payment transaction is fraudulent, explains why,
and shows the result in a dashboard. It also checks suspicious SMS/WhatsApp
messages and links for scams, and learns from user feedback.

> Work in progress.

## Features (planned)
- Fraud prediction with probability and label (Safe / Suspicious / Fraud)
- Explainable alerts: plain-English reasons powered by SHAP
- Scam message and link checker (focused on common Indian scams)
- Feedback loop: report wrong results and retrain the model

## Tech stack
- Backend: Python, FastAPI
- AI: scikit-learn, XGBoost, MLflow, SHAP
- Frontend: React (Vite), Tailwind CSS, Recharts
- Database: PostgreSQL
- DevOps: Docker, Docker Compose, GitHub
